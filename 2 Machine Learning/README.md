# Machine learning

**Lesson on the site:** [Supervised learning](https://ikathuria.github.io/python-to-ai/app/pages/supervised_learning.html) · [Unsupervised learning](https://ikathuria.github.io/python-to-ai/app/pages/unsupervised_learning.html)

Classic algorithms, one folder each. `S` folders are supervised (learning from labelled examples), `US` folders are unsupervised (finding structure in unlabelled data).

| Notebook | What it covers |
|---|---|
| `S1 Naïve_Bayes_Classifier/` | Naïve Bayes: predicting a drug from patient data |
| `S2 KNN/` | K-nearest neighbours on the Adult census income data |
| `S3 Logistic_Regression/` | Logistic regression: Titanic survival |
| `S4 Linear_Regression/` | Linear regression: insurance costs, plus a vehicle deaths study |
| `S5 Decision_Tree/` | Decision trees on the iris flowers |
| `US1 K_Means/` | K-means clustering of iris flowers |
| `US2 Hidden_Markov_Model/` | Hidden Markov models: states, transitions and the Viterbi path |
| `US4 PCA/` | Principal component analysis on fetal health data |

Datasets download automatically from Kaggle on first run (see the repo's [CLAUDE.md](../CLAUDE.md) for the pattern). Install everything with `pip install -r requirements.txt` from the repo root.
