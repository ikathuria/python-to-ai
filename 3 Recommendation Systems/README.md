# Recommendation systems

**Lesson on the site:** [Why Netflix knows you](https://ikathuria.github.io/python-to-ai/app/pages/recommendation_system.html)

How services decide what to show you next, from similarity scores to movie recommendations on MovieLens.

| Notebook | What it covers |
|---|---|
| `basics.ipynb` | What recommendation systems are and the main approaches |
| `preprocessing.ipynb` | Scaling features (min-max, standardisation) before modelling |
| `classification.ipynb` | A classifier on the Pima diabetes data |
| `svm.ipynb` | Support vector machines |
| `cosine_similarity.ipynb / .py` | Cosine similarity between movies by genre |
| `movie_similarity.ipynb` | Item-to-item recommendations from MovieLens ratings |
| `movie_recommendation.py` | A small script version of the movie recommender |

Datasets download automatically from Kaggle on first run (see the repo's [CLAUDE.md](../CLAUDE.md) for the pattern). Install everything with `pip install -r requirements.txt` from the repo root.
