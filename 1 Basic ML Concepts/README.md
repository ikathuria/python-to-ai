# Basic ML concepts

**Lesson on the site:** [ML basics](https://ikathuria.github.io/python-to-ai/app/pages/ml_basics.html)

The tools every later topic uses: NumPy arrays, matrix maths, PyTorch tensors and Pandas tables.

| Notebook | What it covers |
|---|---|
| `0. Numpy_for_ML.ipynb` | NumPy arrays, indexing and vectorised maths |
| `1. Matrix_Operations.ipynb` | Matrix operations: multiplication, transpose, inverse |
| `2. Torch_for_ML.ipynb` | The same ideas with PyTorch tensors |
| `3. Pandas_for_ML.ipynb` | Loading, cleaning and exploring data with Pandas |
| `Basic_ML_Concepts.ipynb` | Putting it together on real datasets (cars, kidney disease, iris) |

Datasets download automatically from Kaggle on first run (see the repo's [CLAUDE.md](../CLAUDE.md) for the pattern). Install everything with `pip install -r requirements.txt` from the repo root.
