# Generative AI

**Lesson on the site:** [How ChatGPT writes](https://ikathuria.github.io/python-to-ai/app/pages/generative_ai.html)

Models that create text and images, and the tools to check what's real.

| Notebook | What it covers |
|---|---|
| `Baby_GPT/` | Pre-train a small GPT from scratch on recipes (PyTorch) |
| `RAG/` | Retrieval-augmented generation: a simple version and a LangChain + Gemini version |
| `Stable_Diffusion/` | Stable Diffusion in PyTorch, including a Food-101 fine-tune |
| `Deepfake_Detection/` | Spotting deepfakes with transfer learning |

Datasets download automatically from Kaggle on first run (see the repo's [CLAUDE.md](../CLAUDE.md) for the pattern). Install everything with `pip install -r requirements.txt` from the repo root.
