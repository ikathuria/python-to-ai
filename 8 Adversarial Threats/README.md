# Adversarial threats

**Lesson on the site:** [How to fool an AI](https://ikathuria.github.io/python-to-ai/app/pages/adversarial_ai.html)

How models get fooled (adversarial examples, poisoning, prompt injection) and how to rate and reduce the risk. This folder is just getting started.

| Notebook | What it covers |
|---|---|
| `s1.ipynb` | Ranking threats by expected risk (likelihood × impact) |

Datasets download automatically from Kaggle on first run (see the repo's [CLAUDE.md](../CLAUDE.md) for the pattern). Install everything with `pip install -r requirements.txt` from the repo root.
