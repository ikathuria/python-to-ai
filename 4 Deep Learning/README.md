# Deep learning

**Lesson on the site:** [Neural networks](https://ikathuria.github.io/python-to-ai/app/pages/deep_learning.html)

Neural networks from a single neuron up: perceptrons, backpropagation, and full networks in PyTorch.

| Notebook | What it covers |
|---|---|
| `Perceptron/` | The perceptron, the 1958 ancestor of neural networks |
| `Backpropogation/` | Learning logic gates with backpropagation |
| `Neural_Networks/` | A simple neural network from scratch on surgical outcome data |
| `Classification.ipynb` | Classification networks in PyTorch |
| `Regression.ipynb` | Regression networks in PyTorch |
| `NIO/` | Predicting movie success from IMDB metadata |

Datasets download automatically from Kaggle on first run (see the repo's [CLAUDE.md](../CLAUDE.md) for the pattern). Install everything with `pip install -r requirements.txt` from the repo root.
