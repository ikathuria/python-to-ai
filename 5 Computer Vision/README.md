# Computer vision

**Lesson on the site:** [How computers see](https://ikathuria.github.io/python-to-ai/app/pages/computer_vision.html)

Pictures are grids of numbers. Convolutional neural networks (CNNs) learn to recognise what's in them.

| Notebook | What it covers |
|---|---|
| `Basic_CNN.ipynb` | A first convolutional neural network |
| `Colour_CNN.ipynb` | The colour classifier behind the site's live demo |
| `image-classification-using-cnn-94-accuracy.ipynb` | Image classification on a custom dataset |

Datasets download automatically from Kaggle on first run (see the repo's [CLAUDE.md](../CLAUDE.md) for the pattern). Install everything with `pip install -r requirements.txt` from the repo root.
